Git — это программа на моём компьютере, которая хранит историю изменений проекта. Работает без интернета.

GitHub — это сайт, где хранятся копии репозиториев в интернете, чтобы делиться кодом и работать вместе. Git можно использовать без GitHub, а GitHub без Git не работает.

git diff сравнивает рабочую папку с индексом: показывает изменения, которые я сделал, но ещё не добавил через git add.

git diff --staged сравнивает индекс с последним коммитом: показывает то, что уже подготовлено и войдёт в следующий коммит.

git status — показывает состояние репозитория: какие файлы изменены, какие уже в индексе, какие Git ещё не отслеживает.

git diff — показывает, что именно изменилось в рабочей папке по сравнению с индексом.

git diff --staged — показывает, что именно лежит в индексе и войдёт в следующий коммит.

Ветка - это независимая линия разработки в репозитории, которая позволяет параллельно работать над разными задачами: добавлять новые функции, исправлять ошибки или экспериментировать с кодом, не затрагивая основную (стабильную) версию проекта.
